# Aster Vale Photography: landing page (Tailwind CSS v4)

A responsive one-page website for a **fictional** wedding, family and portrait photographer, built with **Tailwind CSS v4**. The final site is plain static files; Tailwind is only used at build time.

**Features**

- Utility-first layout and styling directly in the HTML
- Sticky header with a mobile menu (icons swap via `group-aria-expanded:`)
- Hero with a photo collage, packages with prices, masonry portfolio with category filter
- Reviews on a dark section, FAQ with native `<details>` (no JS), studio hours and map placeholder
- Contact form with validation; invalid fields turn red through the `aria-[invalid=true]:` variant
- Reveal-on-scroll animation that respects *reduced motion*
- Brand colours and fonts defined once in `@theme`

## Project structure

```
index.html        All content, styled with Tailwind utility classes
src/input.css     Tailwind source: @theme tokens, base styles, a few components
css/style.css     GENERATED by Tailwind (do not edit by hand; it's committed so hosting needs no build)
js/main.js        Mobile menu, portfolio filter, form validation, reveal animation
assets/           Images and favicon; SVG placeholders in assets/placeholders/
package.json      Tailwind CLI and the build scripts
```

## How Tailwind works here

1. You style elements with small utility classes right in `index.html`, for example
   `class="rounded-3xl bg-ink p-8 text-paper md:grid-cols-2"`.
2. Brand tokens live in `src/input.css` inside `@theme`. Each colour becomes a set of utilities:
   `--color-sage-500` gives you `bg-sage-500`, `text-sage-500`, `border-sage-500` and so on.
3. The Tailwind CLI scans `index.html` and `js/main.js`, finds the classes you used and writes only those into `css/style.css` (about 29 KB minified).

That's why **you must rebuild after changing classes** in the HTML or the tokens in `src/input.css`.

### Tailwind features used

| Feature | Example | Where |
|---|---|---|
| Responsive prefixes | `sm:`, `md:`, `lg:`, `max-lg:` | Every section |
| State variants | `hover:`, `focus:`, `group-open:`, `empty:hidden` | Buttons, FAQ, form messages |
| ARIA variants | `aria-pressed:bg-ink`, `group-aria-expanded:block`, `aria-[invalid=true]:border-error` | Filter, burger, form |
| Arbitrary values | `lg:grid-cols-[5fr_6fr]`, `tracking-[0.14em]`, `bg-[linear-gradient(...)]` | About, eyebrows, map |
| Opacity modifiers | `bg-paper/90`, `border-ink/10`, `bg-white/5` | Header, borders, reviews |
| Masonry | `columns-1 sm:columns-2 lg:columns-3` + `break-inside-avoid` | Portfolio |
| `@apply` components | `.btn`, `.btn-primary`, `.field`, `.eyebrow` | `src/input.css` |

## Setup and build

Requires [Node.js](https://nodejs.org) 20 or newer.

```bash
npm install
```

While editing (rebuilds `css/style.css` on every save):

```bash
npm run dev
```

Before publishing (minified build):

```bash
npm run build
```

Then preview with any static server:

```bash
python -m http.server 5500
```

and open <http://localhost:5500>.

## Customising

### Colours and fonts

Edit `@theme` at the top of `src/input.css`, then run `npm run build`:

| Token | What it controls |
|---|---|
| `--color-paper`, `--color-paper-dark` | Page and alternate section backgrounds |
| `--color-ink`, `--color-ink-soft`, `--color-ink-muted` | Text, dark sections, secondary text (on light and on dark) |
| `--color-sage-100…600` | Accent: eyebrows, ticks, hover states, "Most booked" badge |
| `--color-error` | Form error text and borders |
| `--font-display`, `--font-sans` | Heading and body fonts. Also update the Google Fonts `<link>` in `index.html` |

If you rename a token (say `sage` → `rose`), also rename the matching classes in `index.html` (`text-sage-600` → `text-rose-600`).

### Texts and prices

All in `index.html`, grouped by HTML comments. If you rename a package, update its `data-session` attribute and the matching `<option>` in the contact form.

### Portfolio filter

Each photo is an `<li data-category="wedding|family|portrait">`, and each filter button has a matching `data-filter`. To add a category, add a button and use the same value on the photos.

### Images

The page uses free stock photos from Unsplash (see [Photo credits](#photo-credits)). Neutral SVG placeholders with the same names live in `assets/placeholders/`.

| File | Where it appears | Recommended size |
|---|---|---|
| `hero-1.jpg` | Hero collage, large | 900×1200 (portrait) |
| `hero-2.jpg`, `hero-3.jpg` | Hero collage, small | 800×1000 (portrait) |
| `about.jpg` | About section | 800×1000 (portrait) |
| `gallery-1.jpg` … `gallery-6.jpg` | Portfolio; mixed shapes look best in the masonry | 800×1000, 1200×800 or 800×800 |

Update the `src`, `width`, `height` and `alt` attributes in `index.html`. Compress photos first, for example with [Squoosh](https://squoosh.app).

### Map

Replace the map placeholder `<div>` with the Google Maps embed `<iframe>` (Share → Embed a map) and keep the classes `aspect-[4/3] rounded-3xl overflow-hidden w-full`. Add `title="Map to [business name]"` and `loading="lazy"`.

### Contact form

The form is validated in the browser but **does not send anything**. To receive messages, add `name="contact" method="POST" data-netlify="true"` (Netlify Forms) or `action="https://formspree.io/f/<your-id>" method="POST"` (Formspree) to the `<form>`, then in `js/main.js` replace the demo block after the `// Demo only` comment with `form.submit();`.

## Deploy

Run `npm run build` first, then publish the folder. `node_modules/` is ignored by git and not needed online.

- **Netlify:** drag the folder onto **Sites → Add new site → Deploy manually**, or connect the repository with build command `npm run build` and publish directory `/`.
- **GitHub Pages:** push the repository and enable **Settings → Pages → Deploy from a branch → main / (root)**. The committed `css/style.css` is served as is.
